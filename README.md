# Student Record Management System

## Project Description
The Student Record Management System is a Python-based terminal application used to manage student information efficiently. It allows users to add, view, search, update, and delete student records. It also calculates grades and generates a student statistics report.

## Objectives
- Manage student records efficiently.
- Reduce manual record-keeping.
- Calculate student grades automatically.
- Store student data permanently using JSON.
- Demonstrate Python programming concepts.

## Features
- Add new student records.
- View all student records.
- Search students by ID.
- Update student information.
- Delete student records with confirmation.
- Calculate grades based on marks.
- Generate a statistics report.
- Save records in a JSON file.
- Handle invalid inputs and file errors.

## Installation and Setup
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open a terminal in the project folder.

## How to Run
Execute the following command:

```bash
python main.py
```

The program creates `students.json` automatically when a student record is saved.
